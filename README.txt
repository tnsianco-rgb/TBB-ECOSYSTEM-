Publish safely:
1. Create a NEW GitHub repository. Keep the existing website unchanged.
2. Upload the contents of this folder to the new repository root.
3. Enable GitHub Pages in Settings > Pages, main branch, /(root).
4. Test mobile and desktop layouts.
5. Add verified Payhip, book, contact and dashboard links before launch.

No checkout URLs, contact details, or dashboard image paths have been invented.
